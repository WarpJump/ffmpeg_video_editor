
## Ключевые особенности

*   **Мгновенный предпросмотр:** Перемещение по таймлайну финального видео без задержек. Генерация фрагментов происходит "на лету" с использованием аппаратного ускорения декодирования (`-hwaccel auto`), если оно доступно.
*   **Smart Cut (Умная склейка):** Финальный рендеринг не перекодирует основное тело видео. Пересчитываются только моменты стыков, переходов и наложения эффектов (fade-in/fade-out). Остальное копируется (`copy`), что обеспечивает максимальную скорость.
*   **Управление громкостью:** Возможность усиления громкости основной части видео (до 400%) без влияния на громкость интро.
*   **Веб-интерфейс:** Полностью автономный GUI в браузере (Single Page Application), работающий через WebSocket.
*   **Встроенный файловый менеджер:** Выбор файлов происходит в интерфейсе, ограниченном настроенными директориями (Sandbox), что позволяет безопасно запускать сервер на удаленной машине.
*   **Оптимизация под Linux:** Поддержка работы через RAM-диск (`/dev/shm`) для молниеносной генерации превью и временных файлов.

## Требования

1.  **Python 3.8+**
2.  **FFmpeg:** Должен быть установлен и доступен в `PATH` системы.
3.  **Python-библиотеки:**
    ```bash
    pip install websockets
    ```

## ⚙️ Настройка (config.json)

**Важно:** Для работы скрипта необходимо создать файл конфигурации `config.json` в этой папке проекта (рядом с `gui.py`). Этот файл не хранится в репозитории (`.gitignore`), чтобы настройки путей не перезаписывались при обновлении кода.

1.  Создайте файл `config.json`.
2.  Вставьте в него следующий шаблон и отредактируйте пути под вашу систему:

```json
{
    "BROWSE_ROOT_INPUTS": "/путь/к/вашим/исходникам",
    "BROWSE_ROOT_OUTPUT": "/путь/куда/сохранять/видео",
    "INTRO_DIR": "/путь/к/папке/с/интро",
    "SERVER_PORT": 8766
}
```

### Описание параметров:
*   `BROWSE_ROOT_INPUTS`: Корневая папка, которая откроется при нажатии "Выбрать видео". Скрипт не позволит выйти выше этой директории (безопасность).
*   `BROWSE_ROOT_OUTPUT`: Папка по умолчанию для сохранения готовых файлов.
*   `INTRO_DIR`: Папка, где лежат файлы заставок (например, `intro_new_sponsored_2k.mkv`). Если оставить пустым `""`, скрипт будет искать их в стандартных системных папках документов.
*   `SERVER_PORT`: Порт для веб-интерфейса (по умолчанию 8766).

## Установка и Запуск

1.  Склонируйте репозиторий.
2.  Создайте и настройте `config.json` (см. выше).
3.  Запустите сервер:
    ```bash
    python gui.py
    ```
4.  Откройте браузер по адресу, указанному в консоли (например, `http://127.0.0.1:8766`).

## Интерфейс и возможности

### 1. Настройки
*   **Режим работы:** Один файл (вырезка куска) или Два файла (склейка двух частей).
*   **Громкость видео:** Ползунок для усиления звука лекции (от 1.0x до 4.0x). **Важно:** Это влияет и на предпросмотр, и на финальный файл. Громкость интро остается оригинальной.
*   **RAM-диск:** Рекомендуется включить на Linux для ускорения работы.

### 2. Таймкоды и Файлы
*   Выбор файлов происходит через встроенное модальное окно.
*   Таймкоды задаются в формате `ЧЧ:ММ:СС` или секундах.
*   Кнопка `▶` возле таймкода перематывает виртуальный плеер в точку стыка для проверки точность обрезки.

### 3. Виртуальный Плеер (Предпросмотр)
Показывает, как будет выглядеть и звучать итоговое видео.
*   Использует FFmpeg для генерации 10-секундных превью "на лету".
*   Учитывает настройки громкости, переходы (fade) и склейки.
*   Оптимизирован для слабых машин (использует низкое разрешение и быстрые пресеты кодирования).

## Технические детали

*   **Архитектура:** Сервер на Python (`asyncio` + `websockets`) раздает статику (HTML/JS) и обрабатывает команды FFmpeg. Браузер выступает в роли тонкого клиента.
*   **Финальный рендер:** Используется гибридная схема. Скрипт анализирует ключевые кадры (I-frames) исходника. Перекодируются (re-encode) только малые участки на стыках для применения эффектов `fade` и `volume`. Основная часть видео собирается через `concat demuxer` без потери качества.
*   **Аудио процессинг:** Для изменения громкости и создания плавных переходов аудиопотоки обрабатываются через сложные `filter_complex` графы FFmpeg.
